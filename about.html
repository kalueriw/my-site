Method

How this site is put together

One stylesheet, one navigation, no dependencies.

Five pages share one stylesheet and one navigation. The nav is written once in nav.html and fetched into every page, so adding a page means editing one file. The machine keeps its own stylesheet for the vending machine it draws.

Everything is plain HTML, CSS and JavaScript — no framework, no build step, no dependencies.
