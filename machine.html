    The idea

    Why this is a useless machine

    Claude Shannon built one in 1950. Marvin Minsky described it in 1952. Either way, the machine ends where it began.

    In 1952 the mathematician Marvin Minsky described a machine whose only job was to switch itself off. Claude Shannon built one in 1950 as a joke: a box with one switch, and a hand inside that flipped the switch back.

    This page is that machine on a night shift. Twelve switches, one hand, sixty seconds. You cannot win the board — the machine will keep turning switches off — but you can keep a score. That is the whole joke, and the only reason to go again.

    It has the four parts a useless machine needs. Remove one and it becomes something else:

    Simple
    Twelve switches and one job. Nothing to learn, nothing to configure, no way to read the instructions wrong.
    Unexpected
    It does not turn off the switch you are watching. It turns off the one you just turned on, and looks pleased about it.
    Back to the start
    When the shift ends, the switches are off and the hand is inside. You can start again immediately, and it will be the same.
    Funny, then not
    The first shift is a gag. By the fifth it is a machine with a small amount of power that it will not give up.
