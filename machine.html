    The idea

    Why this is a useless machine

    Minsky described it in 1952. Shannon built the switch version in 1950. Either way, the machine ends where it began.

    In 1952 the mathematician Marvin Minsky described a machine whose only job was to switch itself off. Claude Shannon built one in 1950 as a joke: a box with one switch, and a hand inside that flipped the switch back.

    This one is that joke in the other direction. Instead of switching itself back on, it undoes what you just did. The result is the same: the machine ends where it began, so it can never finish.

    It has the four parts a useless machine needs. Remove one and it becomes something else:

    Simple
    One field and one button. Nothing to learn, nothing to configure, no way to read the instructions wrong.
    Unexpected
    It does not erase some other mark, or the wrong mark. It erases the one you just made, carefully, and looks pleased about it.
    Back to the start
    The card is blank, the arm is parked, the button says the same thing. You can do it again immediately, and it will be the same every time.
    Funny, then not
    The first time it is a gag. By the fifth it is a machine with a small amount of power that it will not give up.
